# L7-BatteryInfo v0.1.1 — release notes draft

This security-maintenance release updates the runtime bundled with the Windows x64 Portable build to .NET 10.0.15. Application behavior is unchanged.

- **Portable (default):** self-contained; no separate .NET installation is required.
- **Slim (optional):** smaller download; requires the .NET 10 Windows Desktop Runtime for x64. Install current runtime security updates separately.

Extract the ZIP and run `L7-BatteryInfo.exe`. Both variants use the same application version and functionality. To update an existing installation, exit the app and replace the executable in its current folder.
